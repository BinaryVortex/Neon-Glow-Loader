# Neon Glow Loader

A colorful neon glow loader built using pure HTML, CSS and JavaScript — lightweight, responsive, and easy to drop into any project.

![Neon Glow Loader Screenshot](./Screenshot%202026-04-27%20at%2009.35.25.png)

---

## Demo

Open `index.html` in your browser to see the loader in action:

1. Clone the repo:

```bash
git clone https://github.com/BinaryVortex/Neon-Glow-Loader.git
cd Neon-Glow-Loader
```

2. Open the file in your browser:

- Double-click `index.html`, or
- Serve the folder (recommended) and visit http://localhost:5500 (or your chosen port) if you use a static server.


## Features

- Pure HTML/CSS/JS — no build tools or dependencies.
- Smooth neon glow animation.
- Small and performant — ideal for splash screens or loading states.
- Easily customizable colors, size and animation speed.

## Usage

Drop the markup from `index.html` into your page and include the CSS and JS (or paste into your stylesheet and script). Customize variables in the CSS to change colors or adjust animation timing.

Example: copy the loader container HTML into your project where you need the loader to appear.

## Customization

- Colors: edit the CSS variables or color rules in the stylesheet to change the neon hues.
- Size: change width/height on the loader container or scale using transform.
- Speed: adjust animation-duration values in the CSS.

If you need help adapting the loader to your project, open an issue and I'll help.
